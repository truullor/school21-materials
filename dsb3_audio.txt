Самоучитель DSB3, аудио-версия. Слушай в дороге или на работе.

Введение. DSB3 — это курс по объектно-ориентированному программированию на Питоне. Проект называется ООП скиллс. Суть одна на весь курс: ты пишешь программу, которая анализирует подбрасывание монеты, то есть считает орлы и решки. И всё задание — это семь упражнений, от нулевого до шестого, в которых ты постепенно переделываешь одну и ту же программу в объектном стиле. Файл с данными data dot csv не меняется ни разу. Каждое упражнение добавляет ровно одну новую идею. Поэтому самое важное — понять общий поток, и тогда остальное пойдёт почти автоматически.

Поток данных всегда такой. Сначала читаем файл data dot csv. Получаем список пар, например ноль-один, один-ноль, ноль-один. Потом считаем, сколько выпало орлов и сколько решек. Потом переводим это в проценты. А позже добавляем предсказания и отчёт.

Правила проекта. Не пиши код просто так на верхнем уровне файла — только внутри функций и методов. В конце каждого файла должен быть блок ifunderscore name равно underscore underscore main underscore underscore, кроме двух особых случаев в упражнениях пять и шесть, там в config dot py и analytics dot py этот блок не нужен. Импортируй только то, что разрешено в шапке упражнения. Работай на ветке develop, а не master. Сейчас репозиторий на master, поэтому в начале создай ветку командой git checkout minus b develop. И пуши только туда.

Теперь быстрый курс ООП. Слушай внимательно, это база.

Класс и объект. Класс — это чертёж или шаблон. Объект, он же экземпляр, — это конкретная вещь, созданная по этому чертежу. Класс создаётся так: слово class, потом имя с большой буквы, потом двоеточие. Например class Research двоеточие. Объект создаётся вызовом класса как функции: r = Research скобки.

Метод — это функция внутри класса. Отличие одно: первым аргументом метода всегда идёт слово self, то есть ссылка на сам объект. Например def file_reader скобки self двоеточие. Внутри класса метод вызывается так: r точка file_reader скобки. Слово self подставляется автоматически, его не пишешь при вызове. Важно: методы могут возвращать значение через return, а класс сам по себе возвращать не может. В упражнении один как раз меняешь print на return.

Слово self, то есть «я сам». Через self метод обращается к данным объекта, например self точка path или self точка data. Конструктор под названием underscore underscore init underscore underscore выполняется автоматически в момент создания объекта и обычно сохраняет пришедшие данные в self, чтобы другие методы их видели. Выглядит так: def underscore underscore init underscore underscore скобки self, path двоеточие, и внутри self точка path = path. Создаёшь объект так: r = Research скобки кавычки data точка csv кавычки — и вот эта строка попадает в переменную path.

Вложенный класс — это класс внутри класса. Помогает сгруппировать логику. Просто пишешь class внутри тела внешнего класса.

Наследование. Если нужен новый класс, который должен иметь методы старого, пиши class Analytics скобки Calculations двоеточие. Analytics получает все методы Calculations бесплатно и добавляет свои.

Импорт своих модулей. Команда import config подхватит файл config точка py из той же папки. Команда from analytics import Analytics подхватит класс Analytics из файла analytics точка py.

Логирование и запросы — это уже упражнение шесть. Модуль logging пишет события в файл в формате дата, время, сообщение. Модуль requests или urllib отправляет сообщение по веб-хуку в Телеграм.

Теперь пройдёмся по упражнениям, чтобы ты знал дорогу.

Упражнение ноль, простой класс. Файл first_class точка py. Класс называется Must_Read. Он читает data dot csv и печатает его. Пока без методов и конструктора — код просто лежит в теле класса и выполняется при его создании. Файл data dot csv создай сам, он есть в задании, одиннадцать строк данных плюс заголовок head comma tail.

Упражнение один, метод. Файл first_method точка py. Переносишь код в метод file_reader, переименовываешь класс в Research, и вместо print ставишь return. Скрипт должен выводить содержимое файла, как и раньше.

Упражнение два, конструктор. Файл first_constructor точка py. Разрешён импорт sys и os. Создаёшь метод underscore underscore init underscore underscore, который принимает путь к файлу. Метод file_reader берёт путь из self точка path. Если файл по структуре неправильный — выбрасывай исключение. Правильный файл: заголовок из двух слов через запятую, а дальше строки, где либо ноль-один, либо один-ноль, никогда не оба сразу. Путь к файлу теперь передаётся аргументом командной строки, то есть sys точка argv индекс один.

Упражнение три, вложенный класс. Файл first_nest точка py. Метод file_reader получает параметр has_header со значением по умолчанию True и возвращает список списков, например открывающая скобка ноль запятая один закрывающая. Если has_header равно False, не пропускай заголовок. Создаёшь вложенный класс Calculations без конструктора с двумя методами. Метод counts принимает данные и возвращает количество орлов и решек. Метод fractions принимает эти количества и возвращает доли в процентах. Помни: каждая пара — это орел и решка, где единица значит «выпала эта сторона». Значит орлы — это сумма первых элементов всех строк, а решки — сумма вторых.

Упражнение четыре, наследование. Файл first_child точка py. Разрешён импорт sys и from random import randint. Переносишь данные в конструктор класса Calculations, чтобы они хранились в self точка data. Создаёшь класс Analytics, который наследует Calculations. В нём два новых метода. Первый, predict_random, принимает число шагов и возвращает список случайных наблюдений, каждое либо один-ноль либо ноль-один, через randint. Второй, predict_last, возвращает последний элемент данных из file_reader в виде списка.

Упражнение пять, конфиг и модули. Файлы config точка py, analytics точка py, make_report точка py. В config точка py хранишь внешние параметры: num_of_steps для predict_random и шаблон текста отчёта. В этом файле разрешён код в глобальной области для переменных, и блок main не нужен. В analytics точка py переносишь классы из прошлого упражнения и добавляешь метод save_file, который сохраняет данные в файл с заданным расширением. Блок main тут тоже не нужен. В make_report точка py пишешь всю логику программы, импортируешь config и analytics, создаёшь объект, считаешь, формируешь отчёт по шаблону и сохраняешь. Пример отчёта есть в задании: текст про двенадцать наблюдений, пять решек, семь орлов, вероятности сорок один и семьдесят семь сотых и пятьдесят восемь и тридцать три сотых, и прогноз на три следующих наблюдения. Цифры бери из своих реальных данных, не копируй пример как есть.

Упражнение шесть, логирование. Те же три файла. Первая задача: каждый метод каждого класса пишет в файл analytics точка log строку «дата пробел время пробел сообщение», например 2020 дефис 05 дефис 01 пробел 22 двоеточие 16 двоеточие 16 запятая 877 пробел Calculating the counts of heads and tails. Используй модуль logging. Вторая задача: в классе Research добавь метод, который отправляет сообщение в Телеграм через веб-хук, либо «The report has been successfully created», либо «The report hasn't been created due to an error».

Советы напоследок. Самая частая ошибка новичка — забыть слово self в методах и при обращении к данным объекта. Второе — путать return и print: метод должен возвращать данные, а печатать их должна основная программа. Третье — в упражнении три не забудь, что колонки в паре — это орел и решка по отдельности, считай суммы по колонкам, а не по строкам. И главное — не паникуй, это один и тот же проект, он просто растёт.

Учись спокойно, на работе достаточно прочитать теорию из начала, а код писать уже дома по скелетам из основного файла dsb3 справочник точка md. Удачи на защите.
