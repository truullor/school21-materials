# DSB6 — Требования и проверка (chek-list)

## Тесты (PyTest)
> «Создай тесты с помощью PyTest для каждого метода указанных выше классов.»

Тест должен проверять:
1. **типы возвращаемых данных** — методы возвращают `dict`/`list` правильно;
2. **типы элементов** — элементы списков имеют корректные типы;
3. **корректность сортировки** — данные отсортированы.

Итого: для КАЖДОГО метода из Movies + Ratings пишу минимум один тест, проверяющий эти 3 пункта.

## Отчёт (Jupyter Notebook)
> «Готовь отчёт, используя только классы и методы из `movielens_analysis.py`».

Ограничения:
1. **каждый метод** из `movielens_analysis.py` обязан быть использован (кроме класса Tests);
2. **каждая ячейка** блокнота содержит магическую команду `%timeit`;
3. **все прочие импорты и встроенные функции запрещены** в ноутбуке — всё выношу в модуль.

Т.е. в ноутбуке НЕЛЬЗЯ использовать `sorted`, `len`, `open` напрямую — только методы модуля. Если нужно — добавляешь в модуль.
