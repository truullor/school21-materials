# Глоссарий ООП (DSB3) — рус ↔ англ

Быстрая зубрёжка терминов. Читай в дороге, перед сном, в обед.

| Русский | Английский | Коротко |
|---|---|---|
| класс | class | чертёж/шаблон для объектов |
| объект | object | конкретная вещь, созданная по классу |
| экземпляр | instance | то же, что объект (object == instance) |
| метод | method | функция внутри класса (первый аргумент `self`) |
| атрибут | attribute | переменная объекта, напр. `self.path` |
| конструктор | constructor (`__init__`) | метод, запускаемый при создании объекта |
| self | self | ссылка на сам объект («я сам») |
| наследование | inheritance | класс берёт методы другого класса |
| родительский класс | parent / base class | класс, от которого наследуют |
| дочерний класс | child / subclass | класс, который наследует |
| вложенный класс | nested class | класс внутри другого класса |
| модуль | module | файл `.py`, который можно импортировать |
| импорт | import | подключение модуля/класса |
| инкапсуляция | encapsulation | скрытие данных внутри объекта (через `self`) |
| возвращаемое значение | return value | то, что метод отдаёт через `return` |
| исключение | exception | ошибка, которую выбрасывают через `raise` |
| логирование | logging | запись событий в файл (модуль `logging`) |
| веб-хук | webhook | http-запрос наружу (например, в Телеграм) |

## Минимум, который надо вызубрить
`class`, `object`/`instance`, `method`, `attribute`, `self`, `constructor (__init__)`, `inheritance`, `import`, и разница `return` vs `print`.

## Фразы, которые пригодятся
- «создай класс» → `class Research:`
- «сделай объект» → `r = Research()`
- «добавь метод» → `def file_reader(self):`
- «сохрани в объект» → `self.path = path`
- «унаследуй» → `class Analytics(Calculations):`
- «импортируй свой модуль» → `from analytics import Analytics`
