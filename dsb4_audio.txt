Лекция по DSB4, управление пакетами и виртуальными средами. Слушай в дороге или на работе, просто чтобы узнать темы.

Введение. DSB4 учит, как в Python ставить чужие библиотеки и изолировать их от системы. Главные слова: виртуальное окружение, пип, пакет, модуль. Весь проект — про несколько файлов и инструментов, поэтому не бойся их количества.

Виртуальные окружения. Это твоя личная песочница с отдельным Питоном. Создаём командой python3 -m venv имя. Активируем source имя/bin/activate. Теперь пип ставит пакеты только сюда, система не страдает. Деактивация — команда deactivate. Когда окружение активно, переменная VIRTUAL_ENV указывает на папку, а sys.prefix отличается от sys.base_prefix. Поэтому скрипт узнаёт, в каком он окружении, через os.environ.get VIRTUAL_ENV. Если деактивировать — переменная пропадает, и скрипт выдаёт None. Это не ошибка, а ожидаемое поведение, просто объясни на защите.

Модули и пакеты. Модуль — это один файл с кодом. Пакет — папка с файлом __init__.py. Когда пишешь import, Питон ищет файл в списке sys.path: текущая папка, стандартная библиотека и site-packages активного окружения. Абсолютный импорт пишется from имя import функция. Относительный внутри пакета — from точка модуль import функция, точка значит «этот же пакет». Типичная ошибка — ModuleNotFoundError, значит файл не в sys.path. Вторая — relative import без родительского пакета, значит запустили модуль как скрипт. Держи проект в папке src, а файлы связывай импортами, как раньше связывал методы через точку.

Пип и requirements. pip install ставит пакет в окружение. Чтобы зафиксировать состав, пиши pip freeze > requirements.txt. Потом установить всё разом — pip install -r requirements.txt. Это и требует ex02: не ставь пакеты по одному, используй requirements.

Термграф. Библиотека рисует столбчатую диаграмму прямо в терминале. Данные — файл со строками «метка пробел значение». Запуск: python -m termgraph data.txt --color синий.

Бьютифулсуп. Парсер HTML. Скачиваешь страницу через requests, скармливаешь soup = BeautifulSoup(html, html.parser), ищешь блоки по классам и тексту. В ex03 парсишь Yahoo Finance, возвращаешь кортеж значений. Не забудь time.sleep пять секунд — он нужен для следующего упражнения.

СиПрофайл. Профилировщик. Запуск: python -m cProfile -s tottime скрипт. Покажет, где тратится время. tottime — чистое время функции, cumtime — с вложенными, ncalls — сколько раз вызвана. В ex04 уберёшь сон, сменишь http-клиента, сравнишь таблицы.

Пайтест. Библиотека тестов. Пишешь функции test_звёздочка, внутри assert. Запуск: pytest файл. В ex05 минимум три теста на каждую функцию: нормальный случай, тип возврата, исключение.

Итог. DSB4 — не про сложный алгоритм, а про инструменты. Пойми цепочку: venv изолирует, пип ставит, import связывает файлы, cProfile меряет, pytest проверяет. И делай маленькими шагами.
