## 3. По упражнениям (кратко)

### ex00 — `data_types.py`
Вывести список типов: `[int, str, float, bool, list, dict, tuple, set]`.
Ключ: `type(значение)` возвращает сам тип, не строку.

### ex01 — `read_and_write.py` (CSV → TSV)
- Читать построчно, **не терять запятые внутри кавычек**.
- Флаг `inside_quotes`: при `'"' ` переключаем режим — запятая внутри кавычек не разделитель.
- Писать через `\t`. Результат: `ds.csv` (вход) → `ds.tsv` (выход).

### ex02 — `stock_prices.py` (компания → цена)
- `len(sys.argv) != 2` → молча `return` (не падаем на лишних аргументах).
- `company.capitalize()` — приводим к виду из словаря (`Tesla`, `Facebook`).
- Нет в слове → `Unknown company`.

### ex03 — `ticker_symbols.py` (тикер → компания + цена)
- Словарь `COMPANIES = {тикер: [компания, цена]}`.
- Ищем по тикеру: `COMPANIES[ticker.upper()]` (верхний регистр, чтобы `tsla`=`TSLA`).
- Нет → `Unknown ticker`.

### ex04 — `to_dictionary.py` (группировка)
- Вход: список кортежей `(страна, число)`.
- Вывод: `{число: [список стран]}`.
- Шаблон:
```python
result = {}
for country, number in list_of_tuples:
    result.setdefault(number, []).append(country)
```
- Формат печати: `'25' : 'Russia'` (число — строка, через `: `).

### ex05 — `all_stocks.py` (разбор строки с запятыми)
- `sys.argv[1].split(",")` → список кусков; `.strip()` у каждого.
- **Две фазы:** сначала проверить, что ни один кусок не пустой (иначе молча ничего), потом печатать.
- Для каждого: если похоже на тикер (`AAPL`) → компания+цена; если компания (`Apple`) → цена; иначе `Unknown`.

### ex06 — `dict_sorter.py` (сортировка по значению)
- Вывести страны, отсортированные по числу **по убыванию**, при равенстве — по алфавиту.
- Ключ сортировки: `sorted(data, key=lambda c: (-int(data[c]), c))`
  - `-int(data[c])` → убывание числа;
  - `c` → алфавит при равенстве.

### ex07 — `marketing.py` (множества + исключения)
- Три списка email (`clients`, `participants`, `recipients`).
- `to_set(items)` → `set(items)`.
- Разности:
  - `call_center` = `clients - recipients`
  - `potential_clients` = `participants - clients`
  - `loyalty_program` = `clients - participants`
- Неизвестный режим → `raise ValueError(...)`.
- Вывод: `for c in sorted(result): print(c)` (сортировка для стабильного порядка).

### ex08 — `names_extractor.py` + `letter_starter.py` (файлы + f-строки)
- `names_extractor.py`: читает файл с email, пишет `employees.tsv` (колонки `Name\tSurname\tEmail`).
  - `email.split("@")[0].split(".")` → `[имя, фамилия]`; `.capitalize()` на каждом.
- `letter_starter.py`: берёт email из аргумента, ищет его в `employees.tsv`, печатает приветственный абзац с именем через f-строку. Извлечение:
```python
name, surname, email = line.split("\t")
if email == target:
    print(f"{name}, добро пожаловать...")
```
- `.format()` **запрещён**, только f-строки.

### ex09 — `caesar.py` (шифр Цезаря)
- `ord(c)` ↔ `chr(code)`: код символа и обратно.
- Сдвиг только букв, регистр сохраняется, остальное (пробелы, цифры, знаки) — как есть:
```python
pos = ord(c) - ord('a')          # 0..25
result += chr((pos + shift) % 26 + ord('a'))
```
- `decode` = тот же код, но `shift = -shift`.
- Исключения:
  - `len(sys.argv) != 4` → `raise ValueError(...)`
  - кириллица в тексте → `raise ValueError("The script does not support your language yet.")`
- Пример из README: `encode 'ssh ...' 12` → `eet -u ...`; `decode` возвращает обратно.
