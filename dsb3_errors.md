# DSB3 — типичные ошибки (карточка)

Ловушки по упражнениям. Если код не работает — сначала смотри сюда.

## Общие
- **Забыл `self`** в определении метода → `def file_reader():` падает, нужно `def file_reader(self):`.
- **return vs print**: метод должен возвращать (`return`), печатать — в `__main__`. Написал `print` вместо `return` — цепочка ломается.
- **Код в глобальной области**: везде, кроме `config.py` (ex05/06), код только внутри функций/методов + `if __name__`.
- **Лишний импорт**: разрешён только тот, что в шапке упражнения. Лишнее могут срезать на защите.

## ex02
- **Путь не из `self.path`**: `file_reader` должен читать `self.path`, а не хардкодить имя файла.
- **Валидация**: проверяй и заголовок, и что каждая строка — `[0,1]` или `[1,0]`. `[0,0]` и `[1,1]` недопустимы.
- **`sys.argv[1]`**: индекс 1, не 0 (`argv[0]` — имя скрипта).

## ex03
- **Подсчёт по строкам, а не по колонкам**: орлы = сумма первых чисел всех строк, решки = сумма вторых. Не считай «сколько строк».
- **`has_header`**: если `False` — не пропускай первую строку.
- **Возврат** — список списков, а не одна строка.

## ex04
- **`randint`**: `from random import randint`. Пара — либо `[1,0]`, либо `[0,1]` (одна сторона = 1).
- **`predict_last`**: берёт последний элемент из `file_reader`, а не из сгенерированного случайного.

## ex05 / ex06
- **`config.py` без `__main__`**: там только переменные. Вся логика — в `make_report.py`.
- **`save_file`**: расширение передаётся параметром, не хардкодь `.csv`/`.txt`.
- **Формат лога**: `"%(asctime)s %(message)s"` → выводит `2020-05-01 22:16:16,877 сообщение`. Нет времени — не тот `format`.
- **Webhook**: `requests.post(url, data=...)`; `url` — твой Телеграм-хук.
