## Глава 1. Как работает Python

Python — **интерпретируемый** язык: ты пишешь текст в файле, программа `python3` читает его **сверху вниз, строка за строкой** и выполняет.

```bash
python3 файл.py          # запустить скрипт
python3 файл.py аргумент # запустить с аргументом
```

Важные следствия:
- Функция выполняется только там, где её **вызвали**.
- Ошибка в середине файла останавливает всё, что ниже.
- Порядок строк имеет значение: сначала определение, потом вызов.

## Глава 2. Переменные

Переменная — именованная «полочка» для значения. Знак `=` — это **присваивание**, а не «равно»:

```python
age = 20
name = "Пётр"
```

Правила имён: латиница/цифры/`_`, начинаться должно с буквы или `_`, регистр важен (`Name` ≠ `name`).

Сравнение — это `==`. Одинарный `=` в условии — ошибка (SyntaxError или логический баг).

## Глава 3. Типы данных *(нужно для ex00)*

| Тип | Название | Пример | Что это |
|---|---|---|---|
| целое | `int` | `42`, `-7` | числа без точки |
| строка | `str` | `"hi"` | текст, всегда в кавычках |
| дробное | `float` | `3.14` | число с точкой |

## Глава 4. Строки вглубь

### 4.1 Конкатенация и спецсимволы
```python
greeting = "Привет, " + name     # склейка
line = "a" + "\t" + "b"          # \t — таб
text = "первая\nвторая"          # \n — перевод строки
```
`result += char` — добавить символ в конец строки.

### 4.2 Методы строк (выучи таблицу!)

| Метод | Что делает | Пример → результат |
|---|---|---|
| `.upper()` | всё заглавные | `"tsla".upper()` → `"TSLA"` |
| `.lower()` | все строчные | `"TSLA".lower()` → `"tsla"` |
| `.capitalize()` | первая заглавная, остальное строчные | `"tEsLa".capitalize()` → `"Tesla"` |
| `.title()` | каждое слово с заглавной | `"ivan petrov".title()` → `"Ivan Petrov"` |
| `.strip()` | убрать пробелы/`\n` по краям | `" hi ".strip()` → `"hi"` |
| `.split(sep)` | разбить в список по разделителю | `"a,b,c".split(",")` → `['a','b','c']` |
| `sep.join(list)` | склеить список через разделитель | `", ".join(['a','b'])` → `"a, b"` |
| `.replace(a, b)` | заменить подстроку | `"aXa".replace("X","Y")` → `"aYa"` |
| `.startswith(s)` / `.endswith(s)` | начинается/кончается ли | `"file.tsv".endswith(".tsv")` → `True` |

## Глава 5. Условия

```python
if условие:
    ...
elif другое_условие:
    ...
else:
    ...
```

Операторы: `==`, `!=`, `>`, `<`, `>=`, `<=`, `not`, `and`, `or`, `in`, `not in`.

```python
if char == '"':
    ...
elif char == "," and not inside_quotes:
    ...
```

`in` работает со всеми коллекциями:
```python
"Tesla" in COMPANIES      # есть ли ключ в словаре
"," in line               # есть ли символ в строке
```

Ранний `return` — «выйти из функции молча»:
```python
if len(sys.argv) != 2:
    return                # ничего не печатаем, выходим
```

**Мини-практика:** что выведет `"a" == "A"`? А `"apple".capitalize() == "Apple"`?

## Глава 6. Циклы

### 6.1 for по коллекции
`for x in ...` — «для каждого элемента из ...». Что такое «элемент», задаёт коллекция:

| Коллекция | x принимает |
|---|---|
| `"abc"` | `'a'`, `'b'`, `'c'` |
| `[10, 20]` | `10`, `20` |
| `{"A": 1}` | ключи: `'A'` |
| открытый файл | строки файла |
| `range(5)` | `0, 1, 2, 3, 4` |

### 6.2 range()
```python
range(5)         # 0..4
range(2, 10, 2)  # 2, 4, 6, 8 (начало, конец, шаг)
range(5, 0, -1)  # 5, 4, 3, 2, 1
```

### 6.3 break и continue
```python
for x in items:
    if x == стоп:
        break        # выйти из цикла совсем
    if x пропустить:
        continue     # перейти к следующему кругу
```

### 6.4 Вложенные циклы
Цикл внутри цикла — внешний делает шаг, внутренний крутится целиком:
```python
for number, countries in result.items():   # по записям словаря
    for country in countries:              # по списку стран
        print(...)
```

**Мини-практика:** выведи таблицу умножения 3×3 вложенными циклами.

## Глава 8. Словари вглубь *(нужно для ex02–ex06)*

### 8.1 Основы
```python
d = {'Apple': 'AAPL'}
d['Apple']            # значение по ключу
'Apple' in d          # True — проверка наличия КЛЮЧА
d['Tesla'] = 'TSLA'   # добавить пару
```

### 8.2 Уникальность ключей
Дублей ключей не бывает — новое значение **затирает** старое:
```python
d = {}
d['132'] = 'France'
d['132'] = 'Germany'
# d == {'132': 'Germany'}  — France потерялся!
```

### 8.3 Паттерн «группировка в списки» *(сердце ex04)*
Чтобы под одним ключом хранить много значений, значением делают **список**:

```python
grouped = {}
for country, number in list_of_tuples:
    if number not in grouped:
        grouped[number] = []       # ключа нет — заводим пустой список
    grouped[number].append(country)
# {'25': ['Russia'], '132': ['France', 'Germany'], ...}
```

### 8.4 Обратный поиск *(нужно для ex03)*
Словарь отвечает «по ключу → значение», но не наоборот. Чтобы найти ключ по значению — перебери пары:

```python
for name, ticker in COMPANIES.items():
    if ticker == искомый_тикер:
        company = name
        break
```

`.items()` отдаёт пары `(ключ, значение)`, распаковываются сразу в две переменные.

### 8.5 Перебор всех элементов
```python
for key in d:                 # по ключам (по умолчанию)
for key, value in d.items():  # по парам
```

### 8.6 Сортировка *(нужно для ex06)*
Встроенная функция `sorted()` сортирует и **возвращает новый список**:

```python
sorted([3, 1, 2])             # [1, 2, 3]
sorted(words, reverse=True)   # по убыванию
```

Ключ сортировки задаётся параметром `key=` — функцией, которая из элемента делает то, по чему сравнивать:

```python
sorted(data.items(), key=lambda pair: pair[1])       # по значениям
```

`lambda` — функция-одностишка без имени: `lambda x: выражение`.

Трюк для «по числу убыванию, при равенстве по алфавиту»: сравнивай **кортеж** `(-число, имя)` — минус переворачивает порядок числа, а имя при равенстве сравнится по алфавиту естественно:

```python
key=lambda pair: (-int(pair[1]), pair[0])
```

(`pair[1]` — значение, `int()` превращает строку `'25'` в число.)

**Мини-практика:** отсортируй `[('b', 2), ('a', 3), ('c', 1)]` по второму элементу пары по убыванию.

## Глава 9. Множества set *(нужно для ex07)*

Множество — коллекция **уникальных** элементов без порядка:

```python
emails = {'a@x.com', 'b@y.com'}
from_list = set(['a@x.com', 'a@x.com', 'c@z.com'])
# from_list == {'a@x.com', 'c@z.com'} — дубль исчез сам
```

Главное — операции над множествами:

| Операция | Знак | Смысл | Пример A={1,2,3}, B={2,3,4} |
|---|---|---|---|
| разность | `A - B` | в A, но не в B | {1} |
| симметрическая разность | `A ^ B` | только в одном из них | {1, 4} |
| объединение | `A \| B` | всё вместе | {1,2,3,4} |
| пересечение | `A & B` | общие | {2,3} |

Это буквально решение бизнес-задач ex07:
- клиенты, не видевшие письмо → `clients - recipients`
- участники-не-клиенты → `participants - clients`
- клиенты вне мероприятия → `clients - participants`

Обратно в список: `sorted(my_set)` (или `list(my_set)`).

## Глава 10. Функции

```python
def имя(параметры):
    тело с отступом
    return результат   # необязательно

имя(аргумент)          # вызов
```

- До вызова функция не выполняется.
- `return` отдаёт результат наружу И прекращает функцию.
- `return` без значения — просто молча выйти.

### Защитный блок (обязателен во всём проекте!)
```python
def task():
    ...

if __name__ == '__main__':
    task()
```
Читается: «выполни `task()`, если файл запущен напрямую». Никакого кода в глобальной области видимости.

## Глава 14. Символы как числа *(нужно для ex09 — шифр Цезаря)*

У каждого символа есть код (Unicode). Две функции-моста:

```python
ord('a')   # 97  — символ → число
chr(97)    # 'a' — число → символ
```

Алфавит можно двигать арифметикой:
```python
pos = ord('h') - ord('a')          # позиция буквы в алфавите: 7
new_pos = (pos + сдвиг) % 26       # % 26 — замкнуть кольцо после 'z'
new_char = chr(ord('a') + new_pos)
```

`%` — остаток от деления: `(25 + 3) % 26 = 2`, поэтому после `'z'` идёт `'c'`. Это и есть «шифр Цезаря»: сдвиг по кольцу алфавита. Расшифровка — тот же сдвиг в другую сторону (`- shift % 26`). Всё прочее (цифры, пробелы, `@`) не шифруется, а переносится как есть.

Проверить кириллицу можно диапазоном: `'а' <= char.lower() <= 'я'`.

## Глава 15. Типичные ошибки новичка

Мы поймали их все своими руками:

1. **Одиночный `=` в условии** вместо `==` — присваивание вместо сравнения.
2. **Нет отступа у тела функции/цикла** → IndentationError.
3. **Разные имена**: `as file`, а используешь `f` → NameError.
4. **Флаг сбрасывается внутри цикла по символам**, а должен — раз на строку (баг с запятыми в кавычках).
5. **`__name__ == '__name__'`** вместо `'__main__'` → ничего не выводится.
6. **Забыл вызвать функцию** в конце — скрипт молчит.
7. **Лишние `\n`** при записи файлов — помни про конец строки.
8. **Верил, что «работает»** — всегда сверяй вход и выход глазами!
