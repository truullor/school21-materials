## Правило про %timeit (README, глава VIII)
> В каждой ячейке, где есть какой-либо замер, обязательно использование `%timeit`.

`%timeit` замеряет время выполнения кода ячейки автоматически (несколько прогонов, среднее). Вставляется магией в начало ячейки:

```python
%timeit Movies('ml-latest-small/movies.csv').dist_by_release()
```

Что получим: `X ms ± Y ms per loop`. Это и есть ответ по производительности.
