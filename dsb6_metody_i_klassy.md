# DSB6 — Справочник классов и методов

Все классы/методы обязательны к использованию. Можно добавлять свои, но эти — минимум.

## MovieLens структура данных
- `ratings.csv`: `userId, movieId, rating, timestamp` — rating 0.5..5.0, timestamp = Unix-время (сек)
- `movies.csv`: `movieId, title, genres` — название содержит год `(1995)`, жанры через `|`
- `tags.csv`: `userId, movieId, tag, timestamp`
- `links.csv`: `movieId, imdbId, tmdbId`

## 📽 Movies (это я пишу)
Анализ `movies.csv`.

| метод | возвращает | сортировка |
|---|---|---|
| `dist_by_release()` | dict: год → количество фильмов (год вытащить из названия) | по количеству — убыв. |
| `dist_by_genres()` | dict: жанр → количество фильмов | по количеству — убыв. |
| `most_genres(n)` | dict: название фильма → число жанров | по числу — убыв., топ n |

## ⭐ Ratings (это я пишу)

### `Ratings.Movies` (вложенный класс)
| метод | возвращает | сортировка |
|---|---|---|
| `dist_by_year()` | dict: год (из timestamp) → количество оценок | по году — возр. |
| `dist_by_rating()` | dict: оценка → количество | по оценке — возр. |
| `top_by_num_of_ratings(n)` | dict: название → число оценок | по числу — убыв., топ n |
| `top_by_ratings(n, metric=average)` | dict: название → средн./медиана оценок | по метрике — убыв., топ n, **округл. до 2 знаков** |
| `top_controversial(n)` | dict: название → дисперсия оценок | по дисперсии — убыв., топ n, **округл. до 2 знаков** |

### `Ratings.Users` (вложенный класс, наследует от `Ratings.Movies`)
3 метода:
1. распределение пользователей по числу сделанных оценок
2. распределение пользователей по средн./медиане их оценок
3. топ-n пользователей с наибольшей дисперсией их оценок

## Общий базовый класс
- `BaseDataset` — читает файл, хранит `self.header` (заголовок) и данные.
- Имя атрибута с данными: в общем файле сейчас `self.tail`, в файле друга `self.rows`. **Надо согласовать одно имя** (например `self.rows`), чтобы у всех классов данные лежали одинаково.
- `read_csv(path)` — @staticmethod внутри BaseDataset, читает первые 1000 записей (по README про «первые 1000»).

## Ключевые правила методов
- Всё возвращаемое — это **новые объекты** (dict/list), а не мутация данных.
- Сортировка обязательна в каждом методе (README проверяет).
- Числа с метриками — `round(..., 2)`.
